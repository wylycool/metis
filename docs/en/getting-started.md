# Getting Started

English | [简体中文](../zh-CN/getting-started.md)

## 1. Install Metis

Download the package for your platform from [GitHub Releases](https://github.com/wylycool/metis/releases):

- macOS: universal `.dmg`
- Windows: `.exe` installer
- Linux: `.deb` or `.AppImage`

Current packages may not yet have operating-system code signing. On first launch, follow your operating system's prompt to allow the application to open.

## 2. Scan local Skills

Open Metis, go to `Skills`, and run a new scan. Metis checks configured paths for Codex, Claude Code, OpenClaw, Hermes, opencode, and generic Agent Skills.

## 3. Manage sources and updates

Select a Skill to bind a Git source, check for updates, inspect changes, and apply an update after confirmation. Metis creates a local backup before replacing files.

## 4. Add a remote Skill

Choose “Add Skill”, paste a GitHub Skill directory page or repository URL, preview it, and select the Agent paths where it should be installed.

See [Troubleshooting](troubleshooting.md) if something does not work as expected.
