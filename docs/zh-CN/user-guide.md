# 用户指南

[English](../en/user-guide.md) | 简体中文

## Skills 工作区

扫描会读取 Settings 中配置的 Agent 路径，并发现第一层包含 `SKILL.md` 的目录。扫描只读取本地文件，不会连接 Git 远端。

同一个 Skill 安装在多个 Agent 时，首页会合并展示安装位置；详情页可以分别查看和管理这些位置。

## 系统 Git 能力边界

没有系统 Git 时，Metis 仍可以扫描和浏览本地 Skills、管理路径、查看本地状态，并把当前已安装 Skill 复制到其他本地位置。

以下操作需要本机可用的系统 Git：预览远端来源、测试连接、从远端安装、检查更新、查看远端差异和应用来源更新。Metis 1.5.0 缺少系统 Git 时不支持这些远端功能。

## 来源和更新

绑定来源时需要提供 Git 仓库地址、仓库内 Skill 目录以及分支或其他 ref。检查更新是用户主动操作；Metis 不会在浏览详情页时后台 fetch。

来源表单中的“信任此来源并加入一键更新列表”会同时把来源标记为可信，并把对应 Skill 加入一键更新候选。只有可信、已加入列表且本地没有修改的 Skill 才会被一键更新；取消该设置后仍可继续手动检查和更新。

更新前建议确认：

- 来源地址和 Skill 目录正确。
- 文件差异符合预期。
- 本地修改是否需要保留。
- 安全提示中是否出现脚本、可执行文件、敏感路径或疑似密钥。

覆盖式更新会先创建备份。手动更新可以覆盖本地修改，因此确认对话框中的目标 Agent 和路径很重要。

## 备份和回滚

Metis 在覆盖更新前保存备份。详情页可以查看已有备份并恢复。回滚同样会先保留当前状态，便于恢复操作前的内容。

备份属于本机数据。删除应用数据或手动清理备份目录前，请先确认不再需要恢复旧版本。

## 添加远端 Skill

“添加 Skill”支持 GitHub Skill 目录页面、仓库首页或 clone URL。目录页面通常可以自动识别仓库内路径；仓库首页可能需要手动填写 Skill 目录。

预览成功后选择目标 Agent 或自定义路径。合法的已有 Skill 只有在用户明确确认时才会覆盖；普通冲突目录不会被当作 Skill 覆盖。

## 本地复制到其他 Agent

详情页的安装位置使用当前本地 Skill 作为复制来源：

- 不检查远端更新。
- 不执行 clone、fetch 或 checkout。
- 不覆盖已有目录。
- 目标路径必须是 Settings 中允许的 Agent 或自定义路径。

## Settings 工作区

- 查看和修改内置 Agent 路径。
- 添加、编辑或删除命名的自定义监控路径。
- 检测本机 Git 是否可用。
- 管理可信来源和一键更新列表。
- 控制启动时检查 Metis 软件更新，并可手动检查。

一键更新只处理可信、已加入列表且本地没有修改的 Skill；其他情况仍需要手动检查和确认。

## Metis 软件更新

- 启动检查可以在 Settings 中关闭，失败不会影响本地 Skill 管理。
- 用户也可以在 Settings 中手动检查 Metis 新版本。
- 发现新版后，只有用户明确确认才会下载安装包。
- Metis 会校验安装包，并把通过校验的文件保存到系统 Downloads。
- Metis 不会自动安装、提权、退出或重启；用户需要手动完成系统安装。

Skill 来源更新与 Metis 软件更新是两套独立流程：前者更新用户管理的 Skill，后者只检查和下载 Metis 应用的新版本。

## 私有仓库

Metis 不提供 Token 输入框，也不保存凭据。请先在终端中配置并验证系统 Git、SSH agent 或 Git credential helper，然后再在 Metis 中测试相同来源。
