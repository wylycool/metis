# 快速开始

[English](../en/getting-started.md) | 简体中文

## 1. 安装 Metis

前往 [GitHub Releases](https://github.com/wylycool/metis/releases) 下载适合当前系统的安装包：

- macOS：universal `.dmg`
- Windows：安装程序 `.exe`
- Linux：`.deb` 或 `.AppImage`

当前安装包可能尚未完成系统级代码签名。首次启动时，请根据操作系统提示确认是否允许打开。

## 2. 扫描本地 Skills

打开 Metis 后进入 `Skills`，点击重新扫描。Metis 会检查已配置的 Codex、Claude Code、OpenClaw、Hermes、opencode 和通用 Agent Skills 路径。

## 3. 管理来源与更新

选择一个 Skill 后，可以绑定 Git 来源、主动检查更新、查看差异，并在确认后更新。覆盖式更新前，Metis 会创建本地备份。

## 4. 添加远端 Skill

点击“添加 Skill”，粘贴 GitHub 中的 Skill 目录页面或仓库地址，预览后选择需要安装的 Agent 路径。

如遇问题，请查看[故障排查](troubleshooting.md)。
