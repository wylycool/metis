# Code of Conduct / 社区行为准则

[English](#english) | [简体中文](#简体中文)

## English

Metis welcomes respectful participation from people of all backgrounds and experience levels.

Participants are expected to:

- Communicate respectfully and focus criticism on ideas and code.
- Provide useful context and avoid harassment, insults, threats, or discriminatory language.
- Respect privacy and never publish another person's credentials, private data, or identifying local information.
- Accept maintainer decisions about scope, moderation, and repository safety.

Unacceptable behavior may be removed, and repeated or serious violations may result in temporary or permanent restrictions. Report conduct concerns privately through the repository maintainer's GitHub profile or an appropriate private GitHub reporting channel.

## 简体中文

Metis 欢迎不同背景和经验水平的用户与贡献者友善参与。

参与者应当：

- 尊重他人，批评应针对观点和代码本身。
- 提供有用上下文，不使用骚扰、侮辱、威胁或歧视性语言。
- 尊重隐私，不公开他人的凭据、私有数据或可识别个人的本地信息。
- 尊重维护者对项目范围、社区管理和仓库安全作出的决定。

不当内容可能被删除；重复或严重违规可能导致临时或永久限制。行为准则问题请通过维护者的 GitHub 主页或合适的 GitHub 私密渠道报告。
