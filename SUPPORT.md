# Support / 获取帮助

[English](#english) | [简体中文](#简体中文)

## English

Before asking for help:

1. Read [Getting Started](docs/en/getting-started.md), [Troubleshooting](docs/en/troubleshooting.md), and the [FAQ](docs/en/faq.md).
2. Search existing GitHub Issues.
3. Confirm that you are using a package from this repository's GitHub Releases.

For a new bug report, include the Metis version, operating system, reproduction steps, expected behavior, actual behavior, and sanitized logs. Remove tokens, private repository URLs, personal information, and complete local paths.

- Bugs and feature requests: GitHub Issues
- Usage questions and discussion: GitHub Discussions
- Security vulnerabilities: private reporting described in [SECURITY.md](SECURITY.md)

## 简体中文

寻求帮助前：

1. 阅读[快速开始](docs/zh-CN/getting-started.md)、[故障排查](docs/zh-CN/troubleshooting.md)和[常见问题](docs/zh-CN/faq.md)。
2. 搜索现有 GitHub Issues。
3. 确认使用的是本仓库 GitHub Releases 中的安装包。

报告新问题时，请提供 Metis 版本、操作系统、复现步骤、预期行为、实际行为和脱敏日志。请移除 Token、私有仓库地址、个人信息和完整本地路径。

- Bug 和功能建议：GitHub Issues
- 使用问题和讨论：GitHub Discussions
- 安全漏洞：按照 [SECURITY.md](SECURITY.md) 私下报告
